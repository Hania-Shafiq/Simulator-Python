# Sapphire Queue Simulator 🚀

**Advanced Queueing Theory Simulation with CP-Based Methodology**

[![Python](https://img.shields.io/badge/Python-3.8+-blue)](https://www.python.org/)
[![GUI](https://img.shields.io/badge/GUI-Tkinter-orange)](https://tkinter.com/)

## 📌 Overview

A comprehensive queue simulation system implementing CP-based (Cumulative Probability) methodology for accurate queueing theory analysis. Features a modern GUI with support for six queue models and multiple probability distributions.

## ✨ Features

### 🎯 **Advanced Simulation**
- **CP-based methodology** (stops at CP=0.99999)
 <img width="1919" height="766" alt="image" src="https://github.com/user-attachments/assets/afc16168-d921-4d8d-bbd8-da2a2b68f27c" />

- **Six queue models**: M/M/1, M/M/c, M/G/1, M/G/c, G/G/1, G/G/c
- **Five distributions**: Exponential, Poisson, Uniform, Normal, Gamma
- **Inverse transform method** with theoretical CDFs

### 📊 **Complete Analysis Suite**
- **Real-time simulation** with performance metrics
- **Analytical formulas** for theoretical comparison
- **Interactive charts** and Gantt visualization
- **Sensitivity analysis** for parameter optimization

### 🖥️ **Modern GUI**
- Intuitive setup and configuration
- Real-time results display
- Export functionality (CSV & reports)
- Professional visualization tools
